Field Note · I04 / 08
DATA FLYWHEEL

从用户行为到模型迭代
断在了 第二步

大部分企业在 PoC 阶段能跑通 AI 能力,但产品上线后,数据没有回流到训练集。

3 个月后模型性能开始衰减,一年后被新需求超越。这不是模型的问题,是工程链路的问题。

真正的飞轮:用户行为日志 → 自动标注 pipeline → 周度增量训练 → A/B 灰度 → 留存数据 → 回流。每一步都需要工程化投入。

的 AI 项目在上线第二年因数据飞轮断层而失去优势

Field Note · II06 / 08
EVALUATION FRAMEWORK

建立可量化的
四维评估矩阵

  • A.
    精度 Accuracy 离线测试集准确率 — 但只能反映 80% 实际表现,真实场景永远更复杂
  • R.
    召回 Recall 覆盖度 — 多少应该命中的真的命中了,跟业务直接挂钩
  • K.
    业务 KPI 转化率 / 留存 / GMV — 真金白银,不可替代
  • F.
    用户反馈 NPS + 投诉率 + 主动反馈 — 量化的"用户感受"
